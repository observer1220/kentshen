Cloudflare Workers 與 Pages 差在哪？我踩過的三個坑

兩者在 Dashboard 上長得很像，但底層是不同產品。指令用錯會出現找不到專案的錯誤。

怎麼分辨你的專案是哪一種

最快的方式是看網址：pages.dev 是 Pages，workers.dev 是 Workers。部署指令也不同：

# Workers with Static Assets
$ npx wrangler deploy

# Cloudflare Pages
$ npx wrangler pages deploy
規則很簡單：Workers 的所有指令，就是把 pages 那一段拿掉。
